# Aine Forge Tester 🎮

A collection of games and interactive experiences built with React, TypeScript, and Vite.

## Games Included

- **Tic Tac Toe** — The classic strategy game
- **Connect Four** — Drop pieces and get four in a row
- **Minesweeper** — Find the mines without clicking them
- **Donkey Kong** — Classic arcade platformer
- **2048** — Combine tiles to reach 2048
- **Mountain Bike Trail** — Navigate the terrain
- **Bike Components Finder** — Find the right parts
- **Rock Paper Scissors Lizard Spock** — Expand your strategy

## Featured Games & Scoring

### 1. Tic Tac Toe
A classic 3×3 strategy game where two players alternate placing X's and O's. **Scoring**: There is no numeric score—the goal is simply to get three of your marks in a row (horizontally, vertically, or diagonally) to win. The game ends in a draw if the board fills without a winner.

### 2. Connect Four
A 7-column, 6-row dropping game where players alternate placing colored pieces. **Scoring**: Like Tic Tac Toe, there is no numeric score. The first player to get four pieces in a row (horizontally, vertically, or diagonally) wins. The game ends in a draw if the board fills without a winner.

### 3. 2048
A tile-merging puzzle game on a 4×4 grid. **Scoring**: Points are earned by merging tiles—when two tiles of the same value combine, you score points equal to the value of the resulting tile. For example, merging two 64-tiles creates a 128-tile and awards 128 points. The goal is to reach the 2048 tile, and the game ends when no more moves are possible.
